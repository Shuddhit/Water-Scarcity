Water Scarcity Hotspots in Indian Cities

Project Overview

This project focuses on identifying and understanding water scarcity hotspots in Indian cities.

Objectives

- Understand the causes of water scarcity.
- Identify areas facing water shortages.
- Study the impact of water scarcity on urban communities.
- Explore possible solutions for sustainable water management.

Technology Used

- HTML
- CSS
- JavaScript

Project Type
